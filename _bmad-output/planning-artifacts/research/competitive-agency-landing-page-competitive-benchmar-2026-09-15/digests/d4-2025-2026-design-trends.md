# Digest: 2025/2026 UI/UX Design Trends for Web Agencies

## 1. Bento Grids 2.0 (Dynamic & Interactive)
- Interactive micro-widgets embedded in cards (interactive code preview, metric counters, live component sandboxes).
- Sub-pixel borders (`border-white/10`) with radial gradient spotlight hover effects tracking the cursor.

## 2. Dark Mode Obsidian / OLED Aesthetic
- Ultra-deep dark backgrounds (`#070709`, `#0d0d12`) with ambient glow meshes (violet, cyan, emerald).
- Tactile SVG noise / micro-grain overlays to prevent gradient banding and add a physical feel.
- High-contrast typography: Sharp sans-serifs (Geist, Inter, Satoshi) with monospaced metadata badges (`[V2.4]`, `AVAILABLE_Q3`).

## 3. Framer Motion & Kinetic Interaction
- Spring-physics transitions (`stiffness: 300, damping: 25`) on magnetic buttons, cursor followers, and card expansions.
- Smooth scroll integration (Lenis / GSAP / Framer Motion scroll triggers).
- Video and interactive WebM preview on card hover.
