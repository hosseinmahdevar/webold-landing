# سند ضمیمه فنی و تکمیلی (Addendum)

## ۱. استک فنی پیشنهادی برای فاز معماری (Recommended Tech Stack)
- **Framework:** Next.js 15+ (App Router)
- **UI Library:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4
- **Animation & Physics:** Framer Motion (یا Motion) + Lucide Icons
- **Scroll Engine:** Lenis Smooth Scroll
- **Forms & Validation:** React Hook Form + Zod
- **Deployment:** Vercel / Docker Container

## ۲. پالت رنگی و استایل پیشنهادی (Visual Tone)
- **Backgrounds:** `#070709` (Dark Obsidian) / `#0d0d12` (Card Surface)
- **Accents:** Electric Violet (`#8B5CF6`) / Cyan Neon (`#06B6D4`) / Emerald Green (`#10B981`)
- **Typography:** فونت‌های مدرن فارسی هندسی (مثل Dana، Peyda یا Shabnam) ترکیب با فونت‌های انگلیسی Geist / Inter.
